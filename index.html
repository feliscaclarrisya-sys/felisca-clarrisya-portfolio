PROJECT 02 · MACHINE LEARNING

Lifestyle Disease Risk

Classifies low versus high disease risk from lifestyle and basic health indicators. The data is a public synthetic set, so the app is a methods demo, not a medical tool.

83%Test accuracy
0.62High-risk precision
0.81High-risk recall
0.70High-risk F1

BMI and blood pressure raise predicted risk. Sleep hours and daily steps lower it.

16,000 test rows. SMOTE was applied to the training set only.

Streamlit checker. Open the app.

What I worked on

  • Feature engineering for blood pressure, obesity, low sleep, and a simple risk score.
  • Scaling and SMOTE fitted on the training set only.
  • Logistic regression tuned with grid search, then read through the coefficients.
  • Streamlit deployment.

GitHub repository
